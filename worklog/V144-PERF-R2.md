# V146 — PERF-R2: ریشه‌کنی لگ/باتری/طوفان درخواست

مبنای کار: پرامپت مالک «رفع لگ، هنگ و کندی بارگذاری» + «اول اندازه‌گیری، بعد تغییر». پیش از هر پچ، کل زنجیره شبکه/CPU از کد استخراج شد (۱۱۷ حلقه setInterval، شیم supabase، مسیر /api/db و /api/rpc، اسکیمای Prisma). نکته‌ی معماری مهم: «Supabase» در این بازی در واقع شیم لوکال `public/cdn/npm/@supabase/.../supabase.js` است که همه‌چیز را به بک‌اند خودِ سایت (Next API + Prisma + Postgres) می‌فرستد؛ پس هر `sb.from/sb.rpc` = یک درخواست HTTP به سرورلس. «تریگرهای saves» که مالک از دوران Supabase به یاد داشت، معادلشان الان در کد اپ است (`afterWrite → recomputeScore + clampSaveState`)، نه در دیتابیس — SQL تشخیصی برای صحت‌سنجی این نکته ضمیمه شد.

## اندازه‌گیری (قبل از پچ — از کد)
- **بازده شبکه هر بازیکن آنلاین (تخمین محافظه‌کارانه): ~۴۰-۵۰ درخواست/دقیقه**
  - اخبار: ۳ سامانه‌ی موازی + ۱ کانال مرده = ۱۶/دقیقه (کانال wd20 چون شیم فقط broadcast می‌فهمد هرگز fire نمی‌شد ولی حلقه‌ی پشتیبان ۵ثانیه‌ای شیم روش ۱۲/دقیقه بی‌فایده می‌سوخت)
  - چت باز: ۱۲/دقیقه — و **بدون گارد تب‌مخفی**: با چت باز و صفحه خاموش ادامه می‌داد (نشتی باتری/نت + عامل «اتصال برقرار نشد» پس از بازگشت)
  - event_switches: ۵/دقیقه برای داده‌ای که به‌ندرت عوض می‌شود
  - auth سمت سرور: هر درخواست = findUnique روی sessions با join user (۲۰-۴۰×N کوئری/دقیقه فقط برای احراز هویت)
  - سیو ۸ثانیه‌ای: هر رد = clamp (۲ کوئری کپ) + updateMany + findMany دوباره‌خوانی + recomputeScore (findUnique + upsert + تا ۷ بررسی دستاورد) — حتی وقتی متریک‌ها ذره‌ای عوض نشده‌اند
- **CPU کلاینت**: داک V87 هر ۱.۲ثانیه بدون هیچ گاردی (۵۰ بار/دقیقه Recalc حتی وسط پن)، تیک آموزش هر ۱ثانیه، بازسازی اورلی الگو هر ۳ثانیه
- **رتبه‌بندی سرور**: جدول scores هیچ ایندکسی روی (server, score) نداشت = اسکن کامل
- چیزهایی که با ممیزی **تأیید شد از قبل درست‌اند** (لازم نبود دست بزنیم): preferCanvas فعال، پرچم/مرز/leaflet لوکال + کش immutable در vercel.json، wd-quiet و wd-low-power (V132)، گارد تب‌مخفی روی اکثر حلقه‌ها (V59 wave-2)، سیو فقط-با-تغییر سمت کلاینت (`if(j===ACC.last)return`)، رندر کشور تک‌لمسی (V125)، ساخت پرچم/ساده‌سازی هندسه time-sliced (V138)، لود تنبل box5/cv-engine/oly3d/shop-v2.
